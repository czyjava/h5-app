## 关键页面理解

### 首启会员购买页

- 新版本首屏不再直接进入短信登录门禁，启动后先展示会员购买页，右上角提供“跳过”。
- 购买页定位为“室内设计 / AI一键焕新”，强调“上传毛坯房，秒看精装效果”。
- 套餐包含年会员、季度会员、月会员；年会员默认选中并标记“新人专享”。
- 会员权益包括全屋设计、户型图设计、旧房改造、设计助手；支付方式展示支付宝。
- 运行日志中购买页请求过 `goods/get-channel-code.htm`、`goods/get-goods-list.htm`、`goods/get-goods-by-external-product-ids.htm` 等接口。

### 首页

- 顶部标题为“AI装修大师 / 看见家的千万种可能”，右侧是“开会员无限用”胶囊。
- 首页主入口由大卡片构成，首屏重点是：
  - `户型图渲染`：智能识别布局，一键生成效果图。
  - `室内设计`：AI智能设计，探索千万种装修风格。
- 底部 Tab 为四项：`首页 / 设计 / 发现 / 我的`，旧 H5 中单独的“设计助手”Tab 不在 5.28.1 底导内。

### 设计上传流程

- 点击底部“设计”默认进入室内设计上传流程；点击首页“户型图渲染”进入户型图上传流程。
- 流程是全屏三步式：
  - 第一步：上传照片或户型图，并展示免费参考示例。
  - 第二步：选择风格，默认现代简约；可见现代简约、新中式、轻奢风、北欧风、奶油风、原木风等风格。
  - 生成前有免费次数提示，并有配色、高品质等 VIP 选项。
- 为避免消耗当前账号权益，本轮没有点击最终“立即生成”。

### 发现页

- 发现页采用二段切换：`室内 / 外观`。
- 室内下按空间分组，如卧室、客厅；外观下按建筑分组，如住宅、别墅。
- 每个分组是横向图片列表，右侧有“查看全部”入口。
- H5 继续优先使用 `recommendList(moduleParam=homeai_discover)` 的真实数据；接口失败时使用本地 5.28.1 风格兜底数据。

### 我的页

- 顶部展示头像、昵称、钻石余额、充值入口和设置入口。
- VIP 横幅强调“AI装修大师 VIP / 立即开通”，权益点为无限次数、高速生成、去品牌 logo。
- 快捷入口包括邀请好友、用户问卷、联系客服。
- 作品区在无作品时展示“这里什么都没有”；登录态存在时继续展示真实作品列表并可进入详情。
