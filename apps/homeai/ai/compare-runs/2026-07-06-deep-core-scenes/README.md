## 室内设计

入口：

- 底部 Tab `设计` 默认进入室内设计。
- 首页 `室内设计` 以及客厅、卧室、厨房、餐厅、卫生间等空间卡片会进入室内设计的不同 `buildingType` 场景；本轮日志确认客厅入口路由为 `featureCode=interior&buildingType=livingRoom`。

流程：

1. 第一页标题为“第一步”，两段进度条。
2. 主标题是“上传照片,AI生成设计方案”。
3. 中间是虚线大上传区，按钮文案“上传图片”。
4. 底部按钮是“下一步”。
5. 不上传时点下一步不会进入后续配置。
6. 点击上传会先弹底部图片要求面板，不会直接进入相册。

上传要求面板：

- 标题：“上传前请先看一下图片要求”。
- 说明：“重点看三件事：空间尽量拍全、光线要明亮、角度最好是正的。”
- 正例标签：空间拍全、光线明亮、角度端正、符合要求。
- 反例标签：只拍局部、画面昏暗、角度歪斜、不符合要求。
- 底部两个按钮：拍照上传、相册上传。
- 首次相册上传会出现 App 自定义权限说明：“为更好的为您提供服务，申请获取以下权限 / 存储权限 / 开启手机存储权限，便于选择创作素材、用户头像、意见反馈图片”，再进入系统媒体权限。

本轮限制：

- 模拟器中系统 MediaStore 已能查询到导入图片，但 App 内置相册选择器仍显示“列表为空”。因此未通过真实上传进入室内第二步。
- 户型图、外观、花园均可通过内置免费样例进入后续步骤，室内设计当前运行态未看到可直接选用的免费样例列表。

## 户型图

入口：

- 首页首屏 `户型图渲染`，路由 `featureCode=floorPlan`。

第一步：

- 标题“第一步”，两段进度条。
- 主标题：“上传户型图,AI生成设计方案”。
- 大上传区按钮：“上传图片”。
- 下方有“示例户型图”横滑列表，这是户型图相对室内设计的关键差异。
- 样例卡片带红色“免费”角标，文字包括“三室两厅”“两室两厅”等。
- 点击样例后，上传区域被样例户型图填充，右上角出现删除按钮；可继续点“下一步”。

第二步：

- 标题“第二步”，两段进度条已全部填充。
- 主标题：“选择心仪风格,创造理想空间”。
- 三列风格网格，首屏可见：现代简约、新中式、轻奢风、北欧风、奶油风、原木风、中式禅意、工业风、美式风、中式科技。
- 默认选中“现代简约”，卡片黄框，右上黑色圆形勾选。
- 底部左侧显示“剩余 3 次免费”。
- 底部右侧有两个灰色小按钮：配色、 高品质，均带黄色 `VIP` 标签。
- 主按钮：“立即生成”。
- 底部合规提示：“禁止利用此功能从事任何非法活动”。

生成前模式面板：

- 点“立即生成”后弹出底部半屏面板“选择生成模式”。
- 快速模式：基于成熟户型案例智能推荐，一键生成全屋设计方案。右侧标“推荐”，默认选中。
- 设计模式：可按需调整布局与房间配置，按房间继续生成个性化效果图。标题旁有锁，右侧标“可调布局”。
- 定制方案：真人设计师一对一沟通需求，产出专属设计方案。右侧标“真人设计师”。
- 底部按钮：“确认选择”。
- 本轮没有点击“确认选择”，未触发户型图生成。

## 室外：外观设计

入口：

- 首页靠近底部的 `外观设计` 卡片。
- 卡片文案：“重塑建筑外观，打造独特外立面”。
- 路由：`featureCode=exterior`。

第一步：

- 标题“第一步”，三段进度条，说明外观设计是三步流程。
- 主标题：“上传您的房屋外观照片”。
- 大上传区按钮：“上传图片”。
- 下方为“参考示例”横滑列表，样例均带“免费”角标，但不展示房型名称。
- 样例图是施工中建筑、毛坯楼体、外立面原始图，不是室内照片。

第二步：

- 标题“第二步”，三段进度条前两段填充。
- 主标题：“请选择建筑类型,AI智能设计外立面”。
- 选项为两列网格：房屋、住宅、别墅、公寓、办公楼、商铺。
- 选中态是黄框 + 右上黑色圆形勾选。本轮选中的是“办公楼”。
- 底部按钮：“下一步”。

第三步：

- 标题“第三步”，三段进度条全部填充。
- 主标题：“选择建筑风格,打造理想外观”。
- 三列风格网格，首屏可见：现代简约、新中式、轻奢风、奶油风、中式禅意、原木风、中式科技、北欧风、美式风、工业风。
- 底部同样有剩余免费次数、配色 VIP、高品质 VIP、立即生成、合规提示。

生成行为：

- 外观设计点击“立即生成”后没有出现户型图那种“选择生成模式”面板，而是直接进入排队页。
- 排队页标题为“外观设计”，显示无限符号 loading、“预计等待58秒”附近的倒计时文案、“可稍后到「我的作品」页面查看结果”。
- 排队页操作：继续创作、返回首页、我的作品。
- 本轮误触了一次外观样例生成，导致免费次数从 3 变为 2；后续记录中的剩余次数以此为背景，不能拿来判断初始额度。

## 发现页

发现页不是生成流程，但与“参考风格/外观灵感”强相关。

- 顶部标题：“发现”。
- 分段切换：室内、外观。
- 室内默认分组：卧室、客厅、厨房等，每组右侧有“查看全部”，下方是横向图片列表。
- 外观分组：住宅、别墅、公寓等，每组右侧有“查看全部”，下方是横向图片列表。
- 发现页外观是案例浏览入口，不替代首页的 `外观设计` / `花园设计` 生成入口。

## H5 复刻关注点

- 首页要补齐长列表功能卡，不能只复刻户型图和室内设计首屏。
- 室外不能只做“发现页外观”；生成能力至少拆成外观设计和花园设计。
- 外观设计是三步流程，多了建筑类型选择；花园设计是两步流程。
- 户型图的生成前模式面板是独有重点：快速模式、设计模式、定制方案。
- 外观设计没有模式面板，点击立即生成会直接进入排队页。
- 样例区的元信息不同：户型图显示房型名称，外观/花园只显示免费角标。
- 上传前图片要求面板至少在室内上传入口出现，后续应确认户型图/外观/花园的真实上传按钮是否也复用各自 `*_guide_good/bad` 引导图。
- VIP 控件位置固定在风格页底部：配色、高品质。
- 免费次数是账号状态，不应写死。本轮因误触外观生成，次数从 3 变 2。

- 室内设计因模拟器相册选择器显示“列表为空”，未进入真实第二步；可在真机或能正常读取相册的模拟器补测。
- 外观设计误触发了一次样例生成，未继续等待完整结果详情页。
- 花园设计未点击立即生成，未确认是否也直接排队或有二次面板。
- 未测试 `换地板`、`涂色设计`、`物品替换` 的完整编辑流程，只记录它们的首页入口和路由形态。
